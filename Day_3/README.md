# Day 3 –  First AI Agent 

## Overview

This  demonstrates how to build an AI-powered bakery assistant using **LangChain and Groq**.

The assistant is designed for Sweet Crumbs Home Bakery. It answers customer questions about cake prices, eggless options, and ordering policies.

## Technologies Used

- Python
- Google Colab
- LangChain
- LangChain Groq
- Groq API
- GPT-OSS 120B
- CSV

## Features

- AI-powered bakery assistant
- Custom system prompts
- Conversation memory
- Customer question answering
- CSV-based chatbot testing
- Test pass percentage calculation
- First LangChain agent creation

## Bakery Menu

| Product | Price |
|---|---:|
| Plum Cake | Rs 500 |
| Chocolate Cake | Rs 650 |
| Cupcake | Rs 80 |

## How to Run

1. Open the notebook in Google Colab.
2. Install the required packages.
3. Add GROQ_API_KEY to Colab Secrets.
4. Upload the faculty-provided test.csv.
5. Run the Python code.
6. Observe the chatbot responses and test results.

## Learning Outcome

Through this project, I learned how to connect a Groq language model with LangChain, create prompt templates, maintain conversation history, test chatbot responses, and create a basic AI agent.
